# E-Commerce Sales & Customer Retention Analysis

## Project Overview
This project uses the Olist e-commerce dataset to analyze seller performance and repeat-customer purchasing behavior using MySQL.

## Tools Used
- MySQL
- MySQL Workbench
- SQL
- GitHub

## Business Questions
1. How do sellers compare in revenue generated from delivered orders?
2. Which customers have placed more than one delivered order?

## SQL Concepts Demonstrated
- Multi-table JOINs
- Aggregate functions such as SUM() and COUNT()
- GROUP BY and HAVING
- COUNT(DISTINCT)
- Window functions for ranking
- Date-based filtering

## Repository Structure
- `sql/` — SQL analysis queries
- `erd/` — Entity-relationship diagram
- `results/` — Query result screenshots

## Project Status
In progress. Data validation and additional business analyses will be added as the project develops.
