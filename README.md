# E-Commerce Sales & Customer Retention Analysis

## Project Overview
This project uses the Olist Brazilian e-commerce dataset to analyze sales performance and customer purchasing behavior using MySQL.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Business Questions
1. How do sellers compare in revenue generated from delivered orders?
2. Which customers have placed more than one delivered order?

## SQL Skills Demonstrated
- INNER JOINs
- Aggregate functions
- GROUP BY and HAVING
- COUNT(DISTINCT)
- Date-based filtering
- Window functions for ranking

## Project Structure
- `sql/` — SQL queries and database structure
- `erd/` — Entity-relationship diagram
- `results/` — Query outputs and visual evidence

## Dataset
The project uses the public Olist Brazilian E-Commerce dataset, available on Kaggle.

## Project Status
In progress. Data validation and additional business analyses will be added as the project develops.
